HELLO KITTY BIRTHDAY SITE

1. Open index.html (double-click on computer, or tap it on phone).
2. Change the name/message: open index.html in a text editor, find "EDIT ME" near the bottom (CFG block).
3. To add your own song: copy your audio file into this folder and name it "music.mp3". (If no music file is added, it automatically plays the built-in chime melody).
4. To share online free: drag this folder onto app.netlify.com/drop and send her the link.

Note: browsers only allow music after a tap, so the gift screen starts it.
Works on iPhone, Android, tablets and computers.
